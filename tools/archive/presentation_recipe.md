# Premium Presentation Template for Kasona Presentation System

This script generates high-impact institutional presentations in Markdown format.

Required sections:
1. Title & Header (Ticker, Exchange)
2. Investment Thesis Summary
3. Financial Snapshot (Key metrics)
4. Strategic Vision
5. Porter's Five Forces Analysis
6. Risk Audit (Bull/Bear cases)
7. Governance & Leadership

The output should be "WOW" - using clean formatting, highlights, and professional language.
